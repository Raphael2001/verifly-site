Verifly Privacy Policy

Last updated: 2026-09-30

Verifly is a browser extension that fills one-time verification codes from your open webmail tab (Gmail, Outlook on the web, Yahoo Mail) into login forms.

What Verifly accesses

  • Email content in your open mail tabs. Only after you grant access from the extension popup. Verifly reads the visible message list and open messages in that tab to find the newest verification code.
  • Web page content. A content script looks at the pages you visit only to detect one-time-code input fields and fill in the code you choose.
  • Verification codes. The codes it finds are used to fill the field or to show in the popup.

What Verifly does with it

  • Everything is processed locally in your browser.
  • Nothing is collected, stored, sold, shared or transmitted to the developer or any third party. There are no servers, accounts, analytics, tracking or ads.
  • Codes and email text are held in memory only while needed and are not saved.
  • The only thing stored is your preference (Suggest or Auto-fill), using the browser's extension storage.

Permissions

  • Mail site access (optional): requested at runtime, not at install; needed to read the verification-code email in the tab you have open. You can revoke it at any time in chrome://extensions.
  • All websites (content script): to detect code fields and fill them.
  • scripting / storage / contextMenus: to read the open mail tab, save your preference and provide the right-click “Fill code from email” option.

Remote code

Verifly does not load or run remote code. All code is included in the extension package.

Children

Verifly is not directed at children and does not knowingly process children's data.
